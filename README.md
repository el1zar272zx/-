# Бот запису для салону

Два Telegram-боти в одному проєкті з спільною базою.

**Клієнтський бот**
- Перший вхід: клієнт ділиться контактом, імʼя й номер зберігаються — далі їх не питають.
- Нижнє меню завжди на екрані: «Записатися», «Послуги та ціни», «Мої записи», «Мій профіль».
- Запис: категорія → послуга (можна кілька в один візит) → дата → час → оплата → заявка майстру.
- Немає вільного часу на дату — можна стати в список очікування; бот напише, коли місце звільниться.
- Нагадування за 24 год і за 2 год, після візиту — прохання оцінити (1–5 ⭐).
- «Мій профіль»: змінити імʼя, оновити номер, кількість візитів.

**Адмін-бот** (нижнє меню + кнопки в повідомленнях)
- Нові заявки: підтвердити / відхилити з причиною; кожну запис можна додати у свій календар (.ics).
- Записи по днях, експорт дня / 7 / 30 днів в один файл календаря.
- Графік роботи (дні, години, винятки на дати, блокування часу), послуги й ціни, реквізити картки.
- Відгуки клієнтів, розсилка всім клієнтам, адміністратори (власник).
- Щоранку о 08:00 — сводка записів на сьогодні; щоночі о 03:00 — копія бази власнику; кнопка «Бекап бази» — копія зараз.

Папка `shared/` — база даних, моделі та вся логіка (одна на обох ботів).

## Запуск

1. У `.env` вкажіть `CLIENT_BOT_TOKEN`, `ADMIN_BOT_TOKEN`, `SUPERADMIN_TELEGRAM_ID` (шаблон — `.env.example`).
2. Двічі клікніть `start.bat` (або в терміналі: `venv\Scripts\python run.py`).
   Таблиці та початкові дані створюються автоматично; нові поля додаються до старої бази самі.

## Перший вхід

1. Відкрийте адмін-бота й натисніть /start. Якщо ви ще не додані — він покаже ваш Telegram ID.
   Впишіть його в `SUPERADMIN_TELEGRAM_ID` та перезапустіть.
2. «🗓 Графік роботи» — налаштуйте дні й години.
3. «💰 Послуги та ціни» — вкажіть ціни для косметології.
4. «💳 Реквізити картки» — введіть реальну картку.
5. Додайте майстра/власницю як адміністратора: «👥 Адміністратори» (потрібен її Telegram ID).

## Важливо

- Майстер один: час блокується для всіх. Місто одне — Жовті Води.
- Нагадування надсилаються лише по **підтверджених** записах.
- Кожен адміністратор має один раз натиснути /start в адмін-боті, інакше Telegram не дозволить боту писати йому.
- Стан діалогів зберігається в памʼяті: після перезапуску клієнти, що були посеред запису, почнуть заново.
- База — файл `salon.db` у папці проєкту. Копія приходить власнику щоночі; можна й просто скопіювати файл.
- Знижка постійним клієнтам вимкнена за замовчуванням; увімкнення — `LOYALTY_DISCOUNT_PERCENT` в `.env`.
- Якщо токен колись потрапив до сторонніх — перевипустіть його в @BotFather (`/revoke`).
